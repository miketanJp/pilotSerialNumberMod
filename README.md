## MOD INTRO

![demo](./demo.gif)<br>
This mod introduces a unique serial number system for each pilot in the game.<br>Every pilot's Biography is automatically assigned a serial in the format:

```PIL-XXXX-XXXX```

The serial is displayed in the pilot’s info card and is generated **only once**. <br>It is cached in memory, preventing duplicates even when the UI is refreshed or the pilot is edited.<br>
On this regard the mod is completely safe to remove, as the value is inserted directly in bio (a value that already exists in vanilla).

### KEY FEATURES
- **Unique serial number** automatically generated for every pilot.
- **In-memory caching** to prevent regeneration during UI refreshes.
- Serial displayed directly in the **pilot’s bio**.
- Compatible with **both the editor and standard pilot view**.
- Safe: does not affect any other pilot stats or attributes.

## INSTALLATION (EPIC GAME VERSION)
To install the mod:

1. Extract the mod folder into the following directory:
<br>```[Drive]:\Users\[yourUser]\AppData\Local\PhantomBrigade\Mods```
<br><br>
2. Launch the game; the mod will be automatically detected and activated.

> ⚠️ [DISCLAIMER] Make sure to back up your save files before applying the mod to avoid any unintended effects.
